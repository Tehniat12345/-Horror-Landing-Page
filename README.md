# The Silent Khander - Horror Landing Page

A single-page, atmospheric horror-themed website landing page built entirely using clean HTML5 and CSS3. 

## 🚀 Live Demo & Preview
* **Layout**: Split-screen interface with a dark text section on the left and a desaturated, foggy castle image on the right.
* **Theme**: Gothic horror aesthetic utilizing a deep black base, textured overlays, and blood-red accent colors.

## 🛠️ Tech Stack Used
* **HTML5**: Single index file structured with semantic headings, paragraph elements, and a main container.
* **CSS3**: Layout styling with Flexbox/Grid, custom horror-themed typography effects, and absolute positioning for metadata overlays.

## ✨ Key Features
* **Localized Horror Copy**: Immersive Roman Urdu description ("Sadiyon purani deewarein...") tailored for a mysterious storytelling experience.
* **Gothic Typography**: Distressed, dripping-style horror font used for the main title to maximize the spooky impact.
* **Easter Egg Metadata**: Subtle coordinates overlayed on the bottom-right corner of the image to look like a real-world haunted location.
* **Themed CTA**: An integrated "ENTER IF YOU DARE" button styled with a thin red border and eerie tracking.

## 📂 Project Structure
```text
├── index.html        # Main and only HTML structure file
├── style.css         # Custom styles, fonts, and dark theme variables
└── assets/           # Folder containing the foggy castle graphic
```

## ⚙️ How to Run Locally
1. **Download or Clone** this project to your directory.
2. Ensure the castle background asset path matches exactly in your local folder structure.
3. Open `index.html` in your browser to experience the horror theme interface.
